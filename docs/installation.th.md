# การติดตั้ง

← [กลับหน้าแรก](../README.th.md) · [English](installation.md)

ไม่มีขั้นตอน build ไม่ต้องติดตั้ง package ไหนเพิ่ม ไม่ต้องมีไฟล์ config เลยด้วยซ้ำ — แค่มี Node.js
ก็มีครบทุกอย่างที่ต้องใช้แล้ว

---

## 1. เช็ก Node.js

```bash
node --version
```

ต้องใช้ **v18.0.0 ขึ้นไป** ถ้ารันแล้วได้เวอร์ชันต่ำกว่านี้หรือเจอ error ให้ไปโหลด Node จาก
[nodejs.org](https://nodejs.org/) (จะเอาตัว LTS ก็ใช้ได้สบายๆ) แล้วลองใหม่อีกที

<details>
<summary>ทำไมต้อง 18?</summary>

API ใหม่สุดที่โค้ดใช้คือ global `fetch` และใช้แค่ตอนเดินเข้า path ของ `--live-usage` เท่านั้น ที่เหลือ
ทั้งหมดเป็น Node built-in รุ่นเก่ากว่านั้น ตัวโปรเจกต์เอง**ไม่มี dependency เลยสักตัว** เพราะฉะนั้นจะไม่มี
อะไรมาแอบดันข้อกำหนดเวอร์ชันให้สูงขึ้นโดยที่เราไม่รู้ตัว

บน Node 18–20 อาจเห็น `ExperimentalWarning` เกี่ยวกับ `fetch` โผล่มาครั้งเดียวตอน `--live-usage` ทำงาน
เป็นครั้งแรก อันนี้เป็นแค่ noise ไม่ใช่ปัญหาอะไร

</details>

## 2. โหลดโค้ดลงเครื่อง

```bash
git clone https://github.com/greentourn/agent-activity-dashboard.git
cd agent-activity-dashboard
```

ไม่มี `git` ในเครื่อง? โหลดไฟล์ ZIP จากปุ่มสีเขียว **Code** ของ repository มาแตกไฟล์ แล้ว `cd` เข้าไปใน
โฟลเดอร์นั้นได้เลย ตัวเครื่องมือไม่ได้อิงกับการอยู่ใน git checkout แต่อย่างใด

> **อย่าหยิบไปแค่บางไฟล์** `server.mjs` ต้องพึ่ง `lib/tool-error-kinds.js` และเสิร์ฟทุกอย่างที่อยู่ใต้
> `public/` (รวมถึง three.js เวอร์ชันที่แถมมาในโปรเจกต์ด้วย) เพราะฉะนั้นต้องเก็บทั้งโฟลเดอร์ไว้ให้ครบ

## 3. รันโปรแกรม

```bash
node server.mjs --open
```

`--open` จะเปิดเบราว์เซอร์พาไปที่ NEURAL CORE (หน้า 3D) ให้เลย ถ้าไม่ใส่ก็ต้องเปิดเองที่
<http://127.0.0.1:7676/brain.html> (หรือ <http://127.0.0.1:7676> ถ้าอยากได้หน้า classic)

จะเห็นแบบนี้บน terminal:

```
  Agent Activity Dashboard
    NEURAL CORE (3D)  → http://127.0.0.1:7676/brain.html
    Classic (2D)      → http://127.0.0.1:7676/
  watching C:\Users\you\.claude\sessions
         + C:\Users\you\.claude\projects
  โควตา: หน้าต่าง 5 ชม. สดจาก transcript · % อย่างเป็นทางการมาจาก cache (ใส่ --live-usage เพื่อดึงสด)

  Ctrl+C to stop
```

มันพิมพ์ URL ของทั้งสองมุมมองไว้ให้เลือกได้จาก terminal เลย — บรรทัดแรกคืออันที่ `--open` เปิดให้

ปิดเซิร์ฟเวอร์ด้วย `Ctrl+C` — มันจะพิมพ์ `stopped` แล้วปิดตัวแบบเรียบร้อย

## 4. เช็กว่ามันเห็น session ของเรา

เปิด (หรือมีรันอยู่แล้ว) Claude Code session สักตัว — จะเป็น terminal, VS Code extension, desktop app,
หรือรันแบบ background ด้วย `--bg` ก็ได้ — แล้วมันจะโผล่มาเป็น node บนจอภายในประมาณ 1 วินาที

**ไม่มีอะไรขึ้นบนจอเลย?** ไม่ได้แปลว่าเป็นบั๊กเสมอไป:

- แดชบอร์ดอ่านข้อมูลจาก `~/.claude/sessions/` และ `~/.claude/projects/` ถ้าเครื่องนี้ไม่เคยรัน
  Claude Code มาก่อนเลย โฟลเดอร์พวกนี้จะยังไม่มีอยู่ ซึ่งถูกต้องแล้วที่แดชบอร์ดจะขึ้นมาว่างเปล่า
  (ไม่ได้ crash แต่อย่างใด)
- session ที่ process จบการทำงานไปแล้วจะยังค้างอยู่บนจอไปอีกตามค่า `--stale-minutes` (ค่าเริ่มต้น 30)
  ก่อนจะหายไป
- ถ้าอยากเห็นหน้าตาทั้งหมดของ interface โดยไม่ต้องมี session จริงเลยสักตัว ใช้ **demo mode**:

  ```
  http://127.0.0.1:7676/?fixture=45
  http://127.0.0.1:7676/brain.html?fixture=cascade
  ```

## เลือกพอร์ต

ค่าเริ่มต้นคือพอร์ต `7676`

```bash
node server.mjs --port 8080
```

ถ้าพอร์ตนั้นถูกใช้ไปแล้ว เซิร์ฟเวอร์**จะไม่**เลือกพอร์ตอื่นแทนให้เองแบบเงียบๆ มันจะพิมพ์
`port 7676 ถูกใช้อยู่ — ลองอีกพอร์ต: --port 7677` แล้ว exit ด้วย status `1`

## ตั้งให้เรียกเป็นคำสั่งจากที่ไหนก็ได้

### วิธี A — ตั้ง alias (ง่ายที่สุด)

```bash
# macOS / Linux — add to ~/.bashrc or ~/.zshrc
alias agent-dash='node /path/to/agent-activity-dashboard/server.mjs --open'
```

```powershell
# Windows PowerShell — add to $PROFILE
function agent-dash { node "C:\path\to\agent-activity-dashboard\server.mjs" --open @args }
```

### วิธี B — `npm link`

จากในโฟลเดอร์ repository:

```bash
npm link
```

คำสั่งนี้จะเพิ่มคำสั่ง `agent-activity-dashboard` เข้าไปใน `PATH` ของเครื่อง (ตัวไฟล์มี shebang ที่
ถูกต้องอยู่แล้ว) `npm link` ไม่ได้ติดตั้งอะไรเพิ่มเลย — เพราะไม่มี dependency ให้ติดตั้งตั้งแต่แรก —
มันแค่สร้าง symlink ให้เท่านั้น

```bash
agent-activity-dashboard --open --port 7777
```

ยกเลิกด้วย `npm unlink -g agent-activity-dashboard`

## รันค้างไว้เป็น background

มันเป็นแค่ HTTP server ธรรมดาที่ไม่มี state ให้เก็บ ดังนั้น process manager ตัวไหนก็ใช้ได้หมด
ตัวเลือกที่ง่ายที่สุด:

```bash
# macOS / Linux
nohup node server.mjs > /tmp/agent-dash.log 2>&1 &
```

```powershell
# Windows PowerShell
Start-Process -WindowStyle Hidden node -ArgumentList "server.mjs"
```

อย่าลืมว่ามัน bind `127.0.0.1` เท่านั้น ดังนั้นคำว่า "background" ในที่นี้หมายถึง *เครื่องนี้เครื่องเดียว*
เท่านั้น — ดู [ความปลอดภัย](#ความปลอดภัย) ด้านล่าง

## ทางเลือกเสริม: เปอร์เซ็นต์โควตาแบบสด

ค่าเริ่มต้น เปอร์เซ็นต์ของ session/รายสัปดาห์ในแถบโควตามาจาก cache ที่ `~/.claude.json` ซึ่ง Claude Code
เป็นคนดูแลไฟล์นี้เอง cache ตัวนี้จะถูกเขียนใหม่แค่ตอน startup กับตอน token renew เท่านั้น เพราะฉะนั้น
บางทีข้อมูลอาจเก่าไปเป็นชั่วโมง หรือผิดไปเลยก็ได้

```bash
node server.mjs --open --live-usage
node server.mjs --open --live-usage-seconds 60   # implies --live-usage
```

พอใส่ flag นี้ เซิร์ฟเวอร์จะเรียก `GET https://api.anthropic.com/api/oauth/usage` ตามช่วงเวลาที่กำหนด
โดยใช้ OAuth token จาก `~/.claude/.credentials.json`

**พูดตรงๆ ว่าต้องแลกกับอะไร:** ตัวเครื่องมือจะกลายเป็นโปรแกรมที่ต้องไปอ่านไฟล์ความลับในเครื่อง ด้วยเหตุผลนี้
แหละมันถึงต้องเป็น opt-in token ตัวนี้เป็น read-only อย่างเดียว ไม่ถูก log ไม่ถูกรวมอยู่ในข้อมูลที่ส่งให้
เบราว์เซอร์ และไม่ถูก refresh หรือเขียนทับเด็ดขาด เซิร์ฟเวอร์เองก็จะประกาศไว้ในบรรทัด startup ด้วยว่า
กำลังทำแบบนี้อยู่

**ส่วนที่ไม่จำเป็นต้องใส่ flag นี้เลย:** หน้าต่าง 5 ชั่วโมงแบบสด — เปิดตอนไหน รีเซ็ตตอนไหน ใช้ไปกี่
token — คำนวณจาก transcript ของเราเองอยู่แล้ว และแสดงผลตลอดเวลาไม่ว่าจะใส่ flag นี้หรือไม่

ถ้าเรียกแล้วโดนปฏิเสธ ตัว poller จะถอยเวลาเรียกออกไปเองอัตโนมัติ (1 → 15 นาที) แล้วคงตัวเลขล่าสุดที่ยัง
ใช้ได้ค้างไว้บนจอ แทนที่จะปล่อยให้แถบว่างเปล่า

## ความปลอดภัย

- เซิร์ฟเวอร์ bind **`127.0.0.1` เท่านั้น** และไม่มี flag ไหนเปลี่ยนพฤติกรรมนี้ได้
- transcript ของเรามีทั้ง prompt และ path ไฟล์อยู่ในนั้น แล้ว `/api/agent` ก็คืนข้อมูลพวกนี้กลับมาแบบ
  เป๊ะๆ **ห้ามเปิดพอร์ตนี้ออกสู่ภายนอก** ผ่าน tunnel, reverse proxy หรือ port forwarding บนเครื่องที่
  ใช้ร่วมกับคนอื่น
- ไฟล์ static เสิร์ฟจาก `public/` เท่านั้น การพยายามทำ path traversal จะถูกปฏิเสธ และ session/agent id
  ทุกตัวจะถูกตรวจกับ `/^[A-Za-z0-9_-]{1,64}$/` ก่อนจะถูกเอาไปต่อเป็น path เสมอ
- แดชบอร์ดไม่เขียนอะไรกลับไปที่ `~/.claude` เลย และไม่ติดตั้ง hook ใดๆ ทั้งสิ้น

## แก้ปัญหาเบื้องต้น

| อาการ | สาเหตุและวิธีแก้ |
| --- | --- |
| `port 7676 ถูกใช้อยู่` แล้ว exit 1 | พอร์ตถูกใช้ไปแล้ว ใช้ `--port 7677` |
| แดชบอร์ดว่างเปล่า ไม่มี error | ไม่มี session ที่ยังรันอยู่ หรือเครื่องนี้ไม่เคยรัน Claude Code มาก่อนเลย ลอง `/?fixture=45` เพื่อพิสูจน์ว่า UI ทำงานปกติดี |
| session ค้างอยู่ที่ `💭 คิดอยู่` เวลาเดินขึ้นเรื่อยๆ | ส่วนใหญ่เป็นเรื่องจริง ไม่ใช่บั๊ก คิดนานเป็นเรื่องปกติ เครื่องมือนี้เลยไม่ขอเดา timeout เอาเอง ถ้าปิดหน้าต่างนั้นไปกลางเทิร์น process อาจยังทำงานอยู่ก็ได้ — ข้อมูลที่มีแยกสองกรณีนี้ออกจากกันไม่ได้ |
| session ที่จบงานไปแล้วยังค้างอยู่บนจอ | ตั้งใจให้เป็นแบบนี้ ค้างไว้ตามค่า `--stale-minutes` (ค่าเริ่มต้น 30) ลดเวลาลงได้ด้วย `--stale-minutes 5` |
| `/brain.html` ขึ้นข้อความ *"เบราว์เซอร์นี้เปิด WebGL ไม่ได้"* | เบราว์เซอร์/GPU เครื่องนี้ไม่รองรับ WebGL หน้าจอนั้นมีลิงก์กลับไปหน้า classic view ซึ่งไม่ต้องใช้ WebGL อยู่แล้ว |
| `/brain.html` จอดำ ไม่โหลดขึ้นมาเลย | boot guard จะเตือนหลังผ่านไป 12 s ลอง `?quality=low` หรือใช้ classic view แทนไปก่อน |
| `--open` เปิดหน้า 3D แต่อยากได้หน้า classic | ตั้งใจให้เป็นแบบนี้ — `--open` เปิด NEURAL CORE เสมอ กดลิงก์ `← หน้าคลาสสิก` ที่แถบควบคุมมุมขวาล่างของหน้า 3D หรือเปิด URL ของหน้า classic ที่พิมพ์ไว้ในบรรทัดถัดไปของ banner บน terminal |
| classic view ไม่มีลิงก์ไปหน้า 3D | ตอนนี้ยังไม่มีลิงก์นั้น ก็อป URL `/brain.html` จาก banner บน terminal (หรือพิมพ์เอง) (ฝั่งหน้า 3D **มี** ลิงก์ย้อนกลับให้อยู่แล้ว) |
| sub-agent ที่ลึกมากๆ ดูเหมือนเป็นลูกของ session โดยตรง | ไม่ควรเกิดขึ้น — ปกติ parent จะถูกดึงกลับมาเชื่อมให้ถูกแม้เกิน send cap แล้วก็ตาม ถ้าเจอแบบนี้ ช่วยเปิด issue พร้อมบอกว่าทำอะไรไปบ้าง |
| tool call เก่าๆ หายไปจาก session ที่ยาวมากๆ | เป็นเรื่องปกติ เพราะแต่ละ transcript ถูก seed มาจากแค่ 256 KB ท้ายสุดของมันเท่านั้น |
| แก้ `server.mjs` แล้วไม่มีอะไรเปลี่ยนเลย | ไม่มี hot reload ต้อง restart เอง |

## ถอนการติดตั้ง

ลบโฟลเดอร์ทิ้งได้เลย ถ้าเคยรัน `npm link` ไว้ก่อน ให้รัน `npm unlink -g agent-activity-dashboard` ก่อน

ไม่มีอะไรถูกเขียนออกไปนอกโฟลเดอร์นี้เลยตั้งแต่แรก — ไม่มี config ไม่มี cache ไม่มีอะไรไปโผล่ใน
`~/.claude`
